# ADR 0000: Short decision title

- **Status:** Proposed
- **Date:** YYYY-MM-DD
- **Deciders:** Unassigned
- **Supersedes:** None
- **Superseded by:** None

## Context

Describe the problem, constraints, current behavior, affected milestone, and
evidence. State which trust or compatibility boundaries are involved.

## Decision

State the decision as a concrete rule. Include scope, rollout, migration,
compatibility, observability, and rollback where applicable.

## Alternatives considered

### Alternative name

Explain the option and why it was not selected. Include “do nothing” when it is
a real choice.

## Consequences

List positive, negative, operational, security, privacy, legal/asset, and
maintenance consequences. Identify follow-up work without presenting it as
already implemented.

## Verification

Link tests, fixtures, measurements, documentation, and the approving pull
request that demonstrate the decision was implemented.
